TRLStats

An online javascript & python application that helps calculate damage stats for the Game 'The Red Lake'!

TRLStats was my first project ever made, a damage calculator for the Roblox Game 'The Red Lake'. The Project is based on a python file, using the python library "Flask" to grab the data from JSON files, and then Javascript to display it.

SBB-History

A Website about the creation of the SBB (Swiss Train Corporation) with an interactable map!

For a School Project, me and 2 friends had to create a page about the economic history of a part of the swiss, which we chose to do about the "SBB", the Swiss Train Coorporation, founded in 1902. It is a simple Website, using HTML, CSS and Javascript, alongside the "Maptiler" API for the interactive map.
